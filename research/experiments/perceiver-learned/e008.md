## Interpretation
The e007 inference ("attention copied from the pooled module stays uniform, so o_proj adds one global vector") is wrong on
its first half: in 30 steps at lr 1e-3 the warm module's attention went from near-uniform (0.93 of log N) to near one-hot
(0.11, max weight 0.74), the same sharpening e003 found in the trained `learned_residual` module, and unlike the collapsed
random-init module, whose attention is still uniform after 488 steps. So the warm start did make the cross-attention
position-selective, and the module is not inert in the e001 sense. What did not change is the output: pairwise cosine
0.994, up from 0.977 at init, i.e. the tokens the LLM receives became more alike, not less. The reason is in the
architecture, not the weights: the output is `norm_out(latents + o_proj(attn))`, the latent grid is 82% one common direction
at native RMS (e005 build: 4.52 RMS, 18% spatial), and `o_proj` at step 30 is at 38% of a trained module's scale on
unit-normed values, so the per-position attention content is a few percent of the shared latent vector and LayerNorm
preserves that ratio (cos 0.994 means the position-dependent part is about 11% of each token's RMS). The LLM does read the
module (trained is 0.33 nats below zeros and 0.05 above the collapsed run's 488-step adapter on the same samples, with a
30-step adapter), but the loss curve cannot leave the collapsed curve while the visible signal is a shared vector plus an
11% per-position perturbation. Cause (b) therefore has a second form for the paper-faithful architecture: not the latent
scale at init (fixed by e005) but the common-direction domination of the latent grid, which drowns the attention branch in
the output at any lr the module can take. The collapsed random-init run has the same problem from a different side
(0.02-RMS random latents drowned by the attention residual, uniform attention). Both runs are the one failure the pooled
anchor avoids: `learned_residual` starts from tokens that already differ per position. Backlog item 3 stays closed as
decided in e007 (no chain; rule pre-registered), but the "untrainable at this data scale" wording is too strong: the
measured obstacle is the shared latent direction, and it is specific and cheap to test.
