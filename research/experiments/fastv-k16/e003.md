## Interpretation
The layer effect saturates by K=16 on DocVQA (+1.2 for +17 % TF) and reverses on character-level OCR: OCRBench -17.3,
almost all from Text Recognition and handwritten math, i.e. tiny single-word images where every glyph token matters,
and TextVQA -2.6. General VQA is flat to slightly up (RWQA +2.4, MMMU +1.0, MMB -0.8). So at 2B 2x, K=16 dominates
K=24: cheaper (8.9 vs 10.5 TF, 363 vs 439 ms) and better on 3 of 4 OCR benchmarks. One plausible reading (unverified,
no attention probe was run): by layer 24 the last query attends to fewer, more semantic tokens, so the 1/2 kept set
skips glyph tokens that later layers still need for exact transcription; DocVQA tolerates that because answers are
words the model can read from surrounding layout. One run per cell, no repeat measured; the 17-pt OCRBench gap (151 of 300 Text Recognition
points) is too large to be eval noise, the 1-2 pt general-VQA differences may be.
