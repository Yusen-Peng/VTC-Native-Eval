## Hypothesis
Backlog item 3, tests cause (b) in isolation on the paper-faithful architecture: the `learned` Perceiver (image-independent
latent queries, no pooled anchor, no gates, LayerNorm output) collapsed because its 0.02-RMS latents were buried under the
O(1) attention residual at step 0 (e001: output pairwise cosine 0.995 at init, uniform attention), not because
image-independent queries are untrainable with a frozen LLM and 66K samples. If the queries start at native scale with
plausible content (the mean native token map) and both residual branches start at zero, the first forward is a clean
RoPE-positioned query grid, the gradient to o_proj/q/k/v is informative from step 1, and the module can learn per-position
(local, via RoPE) attention. e003 adds a sharp mechanistic prediction: the two pooled-anchored modules never used their
cross-attention (gate 1e-4, near one-hot attention); if this module trains at all it must do so through the attention
(nothing else carries image content), so its attention must end far from both one-hot and uniform.

## Interpretation
The warm start did what the build predicted (latents at native RMS, 82% common direction + 18% spatial structure) and the
module loaded and trained without error, but the smoke gives the paper-faithful architecture no credit: with `o_proj` and
`mlp.2` at zero the first forward emits the same image-independent grid for every image, so at step 1 the LLM receives
exactly zero image information (loss 1.32; the random-init collapsed run started at 1.34), and the only way image content
can enter is through `o_proj` growing from exactly zero at compressor lr 1e-3. Adam moves each entry by about lr per step,
so after the 10-step warmup plus 5 full-lr steps the attention branch is a few percent of the native-RMS latent, which is
below what the LLM can read (e001: even a single global image vector is worth 0.27 nats, and this run shows no such gain by
step 15). So the measured outcome is consistent with both readings, "image-independent queries are untrainable at this
data scale" (the direction's counter-argument) and "the zeroed residual branches need tens of full-lr steps before any
signal appears"; the smoke window, fixed before this was worked out, cannot separate them. What is settled: warm-starting
alone does not make the paper-faithful module start anywhere near the pooled-anchored one (0.30 nats apart on identical
batches over 15 steps), so cause (b) as "scale at init" is not the whole story for this architecture; the pooled anchor
(e002) is what gives per-position image content from step 1. The pre-registered abort stands (no 14.5 GPU-h chain on this
evidence). e007 tests the residual-growth caveat for 1 GPU-h: the same configuration on the real schedule and data for one
1 h debug segment (about 37 steps, checkpoint-30 reusable as segment 0 of the chain if it goes), scored at steps 25-37
against the three paired full-data curves (pooled 2x 0.885, learned_residual 2x 0.853, collapsed learned 2x 1.147).
