## Interpretation
The collapse happens inside the compressor at initialisation, and the measurement pins it on cause (b), scale
at init, with a precise mechanism: the latent queries (trunc-normal 0.02) are random and mutually orthogonal
(query cosine 0.001), so every query's attention over the keys is near-uniform (0.996 log N) and the attention
output is the same mean-value vector for all queries; the residual `queries + o_proj(out)` is then dominated by
the shared O(1)-scale `o_proj(out)` term, the 0.02-RMS query identity is drowned, and `norm_out` emits S copies
of one image-level vector (pairwise cosine 0.995 at step 0). 488 steps at lr 1e-4 did not break this symmetry:
output cosine 0.9999 after training, latents RMS still 0.0200. So the LLM never received per-position visual
information; the 0.27 nats it gains over zeros (0.07 over noise) is what one global image vector is worth, and
the trained learned variant is still worse (0.96) than untrained fixed pooling with no LoRA at all (0.82).
Cause (a) is therefore the consequence, not the cause: the LLM did not learn to ignore the tokens, it had
nothing position-specific to read. Cause (c), learning rate, is not excluded as a contributor but cannot be
the primary cause: a symmetric starting point with a drowned query signal gives the latents almost no gradient
at any lr. The pooled mode avoids all of this because its gate-0 init emits exactly the pooled tokens (cosine
1.000 to fixed pooling, gates still only 0.004 after training: the pooled Perceiver is fixed pooling plus a
0.4% perturbation, which is why its numbers equal the "fixed + SFT" row).

## Next
Backlog order stands, with the mechanism now known the fix for the paper-faithful variant (item 3) is
specific: (1) zero-init `o_proj` and the last MLP linear so the step-0 output is the query grid itself
(distinct per position), and (2) latents at the native-token RMS (about 1, not 0.02) so the query identity
survives the residual once `o_proj` grows; a warm-started attention block from the pooled run is optional.
Item 2 (`learned_residual`: pooled queries + zero-init latent grid, tanh gates) remains the cheapest route to
the gate and is next; its risk is that it reproduces the pooled row exactly (gates stay near 0, latents near 0),
which the latents' norm after training will show. The probe script is the fixed measurement for every later
variant (`--conditions` to add rows; `--ratio` for 4x/8x).
