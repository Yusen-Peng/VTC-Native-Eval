## Hypothesis
Backlog item 3, tests cause (b) in isolation on the paper-faithful architecture: the `learned` Perceiver (image-independent
latent queries, no pooled anchor, no gates, LayerNorm output) collapsed because its 0.02-RMS latents were buried under the
O(1) attention residual at step 0 (e001: output pairwise cosine 0.995 at init, uniform attention), not because
image-independent queries are untrainable with a frozen LLM and 66K samples. If the queries start at native scale with
plausible content (the mean native token map) and both residual branches start at zero, the first forward is a clean
RoPE-positioned query grid, the gradient to o_proj/q/k/v is informative from step 1, and the module can learn per-position
(local, via RoPE) attention. e003 adds a sharp mechanistic prediction: the two pooled-anchored modules never used their
cross-attention (gate 1e-4, near one-hot attention); if this module trains at all it must do so through the attention
(nothing else carries image content), so its attention must end far from both one-hot and uniform.
